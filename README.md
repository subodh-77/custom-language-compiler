# Custom Language Compiler

A simple compiler project implementing:

- Lexical Analysis
- Recursive Descent Parsing
- AST Generation
- Semantic Analysis
- x86-64 NASM Assembly Generation

## Features

- Variables
- Arithmetic Operations
- IF-ELSE
- WHILE Loops
- SHOW Statements

## Technologies

- C++
- NASM
- Linux
